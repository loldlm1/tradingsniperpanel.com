1) Acceso + navegación básica

  • URL admin: /admin
  • Idioma: usa el locale preferido (EN/ES).
  • Filtros: barra lateral para búsqueda y segmentación.
  • Subidas: guardar después de adjuntar archivos.

2) Mapa de datos

  • Expert Advisors se conectan a Billing Plans vía entitlements (suscripciones).
  • Marketplace Products crean Billing Plans one-time y dan acceso a EA/Curso/Asset.
  • Add-ons extienden un EA, Curso o Asset específico.
  • Cursos contienen módulos y lecciones.

3) Expert Advisors (EAs)

  1. Crear un Expert Advisor.
  2. Completar nombre, descripción, tipo, tier rank, trial, tags.
  3. Subir archivo del EA y guías EN/ES.

4) Bundles de EA

Los bundles mapean combinaciones de add-ons a archivos descargables.

5) Add-ons de EA (compra única)

Crear un Marketplace Product y configurar el add-on al EA.

6) Cursos

Crear cursos con contenido EN/ES y mantener status en draft hasta completar.

8) Add-ons de cursos (compra única)

Usa Marketplace Products para acceso one-time o add-ons.

9) Assets de marketplace

Crear assets descargables con detalles EN/ES.

10) Productos de marketplace (compra única)

Productos one-time crean su Billing Plan y otorgan acceso.

11) Planes de billing (suscripciones)

Usa key tipo tier_interval (ejemplo: basic_monthly).

12) Entitlements

Definir accesos por plan a EA, Curso y Asset.

13) Facturación manual

Registrar pagos offline como transacciones o suscripciones.

14) Usuarios

Crear/editar usuarios y locale preferido.

15) Reglas + pagos de revenue split

Registrar reglas y pagos por período.

16) Checklists de lanzamiento

  • Nuevo EA: crear EA → add-ons → bundles → entitlements.
  • Nuevo curso: crear curso → módulos/lecciones → entitlements.
  • Nuevo producto marketplace: crear producto → entitlements → add-on.

17) Solución de problemas

  • Dropdown vacío: confirma que el registro existe y está activo.
  • Bundles faltantes: subir bundles requeridos.
  • Error de asset add-on: crear producto base primero.
  • Curso no visible: status en published + published_at.
  • Errores de Stripe: revisar STRIPE_PRIVATE_KEY e IDs.
