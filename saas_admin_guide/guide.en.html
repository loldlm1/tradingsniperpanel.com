1) Access + navigation basics

  • Admin URL: /admin
  • Language: use the account’s preferred locale (EN/ES).
  • Filters: sidebar filters for search and scoping.
  • Uploads: save after attaching files/images.

2) Data model map

  • Expert Advisors connect to Billing Plans via Plan Entitlements (subscriptions).
  • Marketplace Products create one-time Billing Plans and grant access to EAs, Courses, or Assets.
  • Add-ons extend a specific EA, Course, or Asset.
  • Courses contain Modules and Lessons.

3) Expert Advisors (EAs)

  1. Create a new Expert Advisor.
  2. Fill name, description, type, tier rank, trial, tags.
  3. Upload the EA bundle file and guides (EN/ES).

4) EA bundles

Bundles map add-on combinations to downloadable files.

5) EA add-ons (one-time)

Create a Marketplace Product and set the add-on target to the EA.

Track split rules and payout periods.

16) Launch checklists

  • New EA: create EA → add add-ons → upload bundles → link entitlements.
  • New course: create course → add modules/lessons → add entitlements.
  • New marketplace product: create product → add entitlements → configure add-on.

17) Troubleshooting

  • Missing dropdown item: ensure record exists and is active.
  • Bundle coverage missing keys: upload missing bundles.
  • Asset add-on error: create base marketplace product first.
  • Course not visible: set status to published and add published_at.
  • Stripe errors: check STRIPE_PRIVATE_KEY and IDs.
