
# Pandora Box EA

**Pandora Box EA** es un Asesor Experto diseñado para operar en MetaTrader 5, basado en el análisis de breakouts de precios. Utiliza un enfoque automatizado para ejecutar operaciones con parámetros configurables, permitiéndote optimizar tu estrategia de trading.

![Imagen del Sistema](ruta/a/la/imagen.png)

## Descripción Detallada del Funcionamiento

**Pandora Box EA** construye un "box" de precios basado en un rango de tiempo especificado (por ejemplo, de 12:00 a 13:30). Una vez cerrado el "box", se monitorean las rupturas de precio hacia arriba o hacia abajo. Si ocurre una ruptura, el EA ejecuta una operación en una sola dirección y detiene la operación una vez que se haya obtenido una ganancia.

Este sistema automatizado está diseñado para trabajar con estrategias de trading intradía y puede ajustarse según la volatilidad y el comportamiento del mercado.

### Características clave:
- **Automatización Completa**: El EA realiza las operaciones por ti basándose en el análisis técnico de los precios.
- **Parámetros Personalizables**: Ajusta las configuraciones del EA, como el rango de precios, los niveles de stop loss y take profit.
- **Control de lotaje**: Con su función de parar operaciones después de la primera ganancia, puedes gestionar mejor el lotaje en cada operación.

Este sistema es ideal para aquellos que buscan optimizar su tiempo.
